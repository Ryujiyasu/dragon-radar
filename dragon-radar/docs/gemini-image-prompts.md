# Gemini 画像生成 指示書 ─ ドラゴンレーダー 提出用ビジュアル

実機写真2枚をGemini（Nano Banana / Gemini 画像編集）に添付し、下のプロンプトをコピペして提出用画像を作る。

## 素材（添付する実写）
- **A: ドラゴンボール（一星球）** … オレンジ半透明レジン球、中央に赤い5芒星（1つ星）、表面に小さな排液穴。`IMG_1586.jpg`
- **B: レーダー本体** … 白い円形3Dプリント筐体＋丸い緑のレーダー画面（グリッド／スイープ扇／中央のピンク三角＝自機／**黄色い光点＝検出したボール**）。`IMG_1587.jpg`

## 大前提（重要・全プロンプト共通）
- **実物の形・色・質感・画面表示は変えない**（コンテスト応募なので“盛り”は背景/光/構図まで。デバイスや球の見た目・レーダー画面のグリッドや光点を捏造しない）。
- 出力は **16:9・880×495px以上**（ProtoPediaのメイン/構成図推奨サイズ）。1枚目がメイン画像。
- 余計な文字・ロゴは入れない。

---

## ① メインビジュアル（A+B 合成・最重要）
```
添付2枚を1枚に合成してください。
・1枚目(A)=オレンジ半透明の樹脂製“ドラゴンボール”（中央に赤い1つ星）。
・2枚目(B)=丸い緑のレーダー画面を持つ白い円形デバイス。
両方を、暗くクリーンな背景（黒〜濃紺のグラデーション、ソフトな反射のある滑らかな台）に置いたプロダクト写真風に合成。
構図: レーダー(B)を左手前、ドラゴンボール(A)を右奥にやや小さく配置。
演出: レーダー画面の“黄色い光点”からドラゴンボールへ向かう、淡い光のライン／グローを描き「電波で探知している」様子を表現。
維持すべき点: デバイスと球の形・色・質感、レーダー画面の緑のグリッド・中央の三角・黄色い光点は元写真のまま、くっきり鮮明に。
ライティング: シネマティックで上質。被写界深度で背景を軽くボカす。
出力: 16:9・高解像度。
```

## ② ドラゴンボール単体（クリーン）
```
添付のオレンジ色樹脂ドラゴンボール（赤い1つ星）の写真を、
背景を暗い無地（黒〜濃グレー、下にソフトな鏡面反射）に置き換えてください。
半透明レジンが内側から淡く発光するような“ガラス玉”の質感を強調し、赤い星は鮮やかに。
球の形・色・彫り込みの星・表面の質感は元のまま維持。捏造しない。
プロダクト写真風、被写界深度あり、16:9・高解像度。
```

## ③ レーダー本体単体（画面を主役に）
```
添付の白い円形レーダーデバイスの写真から、ごちゃついた背景（3Dプリンタ・ケーブル・机）を消し、
暗い無地のスタジオ背景に置き換えてください。
丸い緑のレーダー画面（グリッド／スイープ扇／中央のピンク三角／黄色い光点）は元のまま、明るくくっきりと。
白い筐体のマットな質感、上部の丸いボタンも維持。
卓上に置いた、または手に持つプロダクト写真風。16:9・高解像度。捏造しない。
```

## ④ システム構成図のベース（任意）
```
クリーンでモダンなテック系の構成図を作ってください（フラットデザイン、白背景）。
要素: 「ドラゴンボール(UWBタグ)」→(UWB測距/AoA)→「レーダー本体(UWB 2BP)」→(UART)→「ESP32-P4 + 丸型LCD」、
さらに「BNO086 IMU(方位)」と「ボタン(レンジ切替)」がESP32-P4に接続。
矢印とアイコンで信号の流れを示す。文字は日本語。16:9。
```
> ※構成図は写真合成より、図として別途作る方が正確。テキスト版の図が要れば私が出します。

## 使い方メモ
1. Gemini に **該当する実写を添付** → 対応プロンプトを貼る。
2. 出てきた画像を確認し「背景もっと暗く」「光点を強調」等で微調整。
3. ProtoPedia：①をメイン(1枚目)、②③を続けて、構成図を4〜5枚目に。
4. 仕上がりが**実機と乖離しすぎたら採用しない**（応募の信頼性優先）。
