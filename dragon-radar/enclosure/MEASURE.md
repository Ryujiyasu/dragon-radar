# 筐体 実測チェックシート

ボード(ESP32-P4-3.4C)とボタン(MKBKLLJY)の現物を測り、`値` 欄を埋める。
各行の `→ 変数` を [`dragon-radar-enclosure.scad`](dragon-radar-enclosure.scad) に転記すれば確定版になる。

- 工具: ノギス(0.1mm)、分度器 or スマホの角度計、定規。
- 角度の基準: **画面を正面、ボタン(天面)を 12 時=90°** とし、**反時計回り(CCW)に +**。
  USB 側を見て「何時の方向か」を角度に直す (3時=0°, 12時=90°, 9時=180°, 6時=270°)。
- 不明な行は空欄でよい (今の仮値のまま進む)。

## 2. マウントネジ (✅確定: 上下非対称な台形)

カラーでボード⇔ディスプレイ締結済。同じ4穴へバックから締めて筐体固定(二段締め)。

| 項目 | 実測 (外形込み) | → 変数 |
|---|---|---|
| 列間 X | **83.6** → x=±41.8 (端から1.0mm) | `mount_holes` x |
| 左列 Y間隔 / 上端→上ネジ | **32** / **8.6** → y=+23.9, −8.1 | `mount_holes` 左 |
| 右列 Y間隔 / 上端→上ネジ | **39** / **8.3** → y=+24.2, −14.8 | `mount_holes` 右 |
| キャリア向き | USB-C上辺を底へ → **180°** | `carrier_angle` |

> ※すべて「外形込み(スタンドオフ外形)」。穴芯はスタンドオフ径ぶん内側になるので、
> テストプリント時に `mount_holes` / `board_screw_dia` を現物穴芯で微調整する。

```
   キャリア基板を裏から見て (長辺=X=86, 短辺=Y=65)
        +Y(32.5)
   ┌──────────────────┐
   │   ○        ○      │   ○=穴。中心からの x,y を測る
 -X│        ＋中心      │+X   (例: ○が中心右30/上15 → [30,15])
   │       ○           │
   └──────────────────┘
        -Y(-32.5)
   ※基板の長辺(X)が筐体のどの向き(時計)を向くか= carrier_angle
```
> ヒント: 基板の縁から穴芯までの距離を測り、中心(=長辺43.0/短辺32.5)から引いて座標化。

## 3. コネクタのリム角度位置 (側壁開口)

## 4. ボタン MKBKLLJY (天面タレット) ✅一部確定

ø12 メタル モメンタリ(LED付・配線済)。端子は柔らかいので**金属取付部だけ保持**、
端子+配線は内部の天面隙間へ逃がす設計 → タレットは短くできる。

| 測る項目 | 実測 | → 変数 |
|---|---|---|
| 全長 | **24** | (設計の基準) |
| 頭(押せる部分)の高さ | **1.7** | (頭はタレット外) |
| 頭先端〜ナット下端 | **6** → パネル≤~2 | `turret_cap_th` = **2.0** |
| パネル裏の必要収納 | ~22(柔) → 14で保持+隙間逃がし | `turret_protrude` = **14.0** |
| パネル穴径(バレルØ) | ______ (ふつう ø12) | `button_dia` = 12.3 [VERIFY] |
| 六角ナット最大外径 | ______ | `turret_bore` = 16.5 [VERIFY] |

> 残2つ ([VERIFY]): **バレル径**(ネジ部の太さ=穴径) と **六角ナットの最大外径**。
> 標準ø12なら 12.3/16.5 のままで概ね収まる。テストプリントで現物合わせ。

```
   ボタン側面                タレット(筐体)に収まるイメージ
  ┌──┐ ←頭                 外  ┌────────┐ 内
  │  │                       │ ┌──────┐ │
 ═╪══╪═ ←パネル(厚)→turret_cap_th  ═╪═│ナット │ │
  │  │                       │ │ 端子 │ │→配線穴
  │░░│ ←バレル+ナット         │ └──────┘ │
  │██│ ←端子                  └────────┘
  └┬┬┘                       └全長=turret_protrude目安┘
   配線                       └bore=端子最大径+クリア┘
```
