# 筐体 実測チェックシート

ボード(ESP32-P4-3.4C)とボタン(MKBKLLJY)の現物を測り、`値` 欄を埋める。
各行の `→ 変数` を [`dragon-radar-enclosure.scad`](dragon-radar-enclosure.scad) に転記すれば確定版になる。

- 工具: ノギス(0.1mm)、分度器 or スマホの角度計、定規。
- 角度の基準: **画面を正面、ボタン(天面)を 12 時=90°** とし、**反時計回り(CCW)に +**。
  USB 側を見て「何時の方向か」を角度に直す (3時=0°, 12時=90°, 9時=180°, 6時=270°)。
- 不明な行は空欄でよい (今の仮値のまま進む)。

## 2. マウント穴 (キャリア基板上・四隅ではない)

キャリア基板(65×86)上の固定穴。**四隅ではない**ので、各穴の位置を
**キャリア中心を原点・長辺=X** とした [x, y] 座標(mm)で測る。

| 測る項目 | 実測 | → 変数 |
|---|---|---|
| 穴の数 | ______ | (`mount_holes` の要素数) |
| 各穴の [x, y] (中心原点, 長辺=X) | ______ | `mount_holes = [[x,y],...]` |
| 穴の径 | ______ | `mount_hole_dia` |
| キャリアの向き(長辺が筐体の何時方向か, 3時=0°) | ______ | `carrier_angle` |

```
   キャリア基板を裏から見て (長辺=X=86, 短辺=Y=65)
        +Y(32.5)
   ┌──────────────────┐
   │   ○        ○      │   ○=穴。中心からの x,y を測る
 -X│        ＋中心      │+X   (例: ○が中心右30/上15 → [30,15])
   │       ○           │
   └──────────────────┘
        -Y(-32.5)
   ※基板の長辺(X)が筐体のどの向き(時計)を向くか= carrier_angle
```
> ヒント: 基板の縁から穴芯までの距離を測り、中心(=長辺43.0/短辺32.5)から引いて座標化。

## 3. コネクタのリム角度位置 (側壁開口)

各コネクタが**画面を正面に見て何時の方向**にあるかを角度(CCW, 3時=0°)で。
開口寸法 = コネクタの幅×高さ + 抜き差しクリアランス(各+1mm程度)。

| コネクタ | 仮角度 | 実測角度 | 幅(周方向) | 高さ(Z) | → 反映先 |
|---|---|---|---|---|---|
| USB-C (給電/UART) | 250° | ______ | ______ | ______ | `connector_cutout()` 1行目 |
| USB-OTG | 270° | ______ | ______ | ______ | 2行目 |
| microSD | 290° | ______ | ______ | ______ | 3行目 |
| (他に開口が要る物) | — | ______ | ______ | ______ | 追加 |

| その他 | 仮値 | 実測 | → 変数 |
|---|---|---|---|
| コネクタ中心の Z 高さ(ガラス前面=0、背面が −) | −7.5 | ______ | `conn_z` |

```
   側壁を上から見た図 (角度)
            90°
       ┌────●────┐ ←ボタンタレット
   135°│         │45°   ●=各コネクタの中心角を記入
       │  ＋中心  │
   180°│         │0°
       │ ░░░ ░░░ │      ░=コネクタ(底側に集約中)
       └─●─●─●─●─┘
      250 270 290  (現仮値)
            270°
```

## 4. ボタン MKBKLLJY (天面タレット)

パネル裏に出る寸法を測る。タレット長はこれで決まる。

| 測る項目 | 仮値 | 実測 | → 変数 |
|---|---|---|---|
| パネル穴径(取付穴, ふつう ø12) | 12.0 | ______ | `button_dia`(+0.3) |
| 推奨パネル厚(ナットが締まる範囲, ふつう ≤5) | 3.0 | ______ | `turret_cap_th` |
| パネル裏〜端子先端までの全長 | 18.0 | ______ | `turret_protrude`※ |
| 端子部の最大外径(ナット込み) | 16.5 | ______ | `turret_bore`(+1) |
| ボタン頭(見える部分)の外径 | — | ______ | (タレット端面径の確認) |

※ `turret_protrude` = (パネル裏全長) − (壁に埋まる分) 目安。配線分の余裕も少し足す。

```
   ボタン側面                タレット(筐体)に収まるイメージ
  ┌──┐ ←頭                 外  ┌────────┐ 内
  │  │                       │ ┌──────┐ │
 ═╪══╪═ ←パネル(厚)→turret_cap_th  ═╪═│ナット │ │
  │  │                       │ │ 端子 │ │→配線穴
  │░░│ ←バレル+ナット         │ └──────┘ │
  │██│ ←端子                  └────────┘
  └┬┬┘                       └全長=turret_protrude目安┘
   配線                       └bore=端子最大径+クリア┘
```
